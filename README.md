# NetBeans Edition: code equivalents

The NetBeans edition of the Week 3 guide builds the same interfaces with the Matisse drag-and-drop designer.
NetBeans stores a designer form as a `.form` file plus generated code, so the files in this folder are the
same windows written directly in Swing code:

| NetBeans form | File here | Notes |
|---|---|---|
| FirstWindow | `FirstWindow.java` | Blue "Click Me!" button, 500x400, centred |
| ShowcaseForm | `ShowcaseForm.java` | 16+ components, three radio buttons in one ButtonGroup |
| FlowDemo, BorderDemo, GridDemo | `../activity3-layout-managers/` | Same layouts as the Activity 3 programs |
| CombinedDemo | `CombinedDemo.java` | Toolbar, sidebar, 3x3 grid, status bar |
| FreezeForm / FixedForm | `../activity4-edt-rule/` | Same freeze and fix pattern as FreezeDemo and FixedDemo |
| Student Portal | `../activity5-student-portal/` | Same mockup, customised for Riara University |
